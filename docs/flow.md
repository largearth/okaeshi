## 概要

本アプリは、以下の流れで支払いから精算までを管理する。

```mermaid
flowchart TD
    A[支払いを登録] --> B[各メンバーの負担額を設定]
    B --> C[請求を作成]
    C --> D[請求対象ユーザーが内容を確認]
    D --> E[指定された財布へ返済]
    E --> F[精算済みにする]
```

---

## 初回利用フロー

```mermaid
flowchart TD
    A[ログイン] --> B{所属グループがあるか}
    B -- ない --> C[グループを作成]
    C --> D[グループ名を入力]
    D --> E[メンバーを招待]
    E --> F[財布を登録]
    F --> G[利用開始]

    B -- ある --> G
```

---

## グループ参加フロー

```mermaid
flowchart TD
    A[招待を受け取る] --> B[招待内容を確認]
    B --> C{参加するか}
    C -- 参加する --> D[グループへ参加]
    D --> E[グループの共有財布を参照]
    E --> F[個人財布を参照]
    F --> G[利用開始]

    C -- 参加しない --> H[招待を辞退]
```

---

## 支払い登録フロー

支払い時点では、負担額や請求内容を決めない。

```mermaid
flowchart TD
    A[支払い登録画面を開く] --> B[タイトルを入力]
    B --> C[金額を入力]
    C --> D[支払元財布を選択]
    D --> E[日付を指定]
    E --> F[必要に応じてメモを入力]
    F --> G{入力内容は有効か}

    G -- いいえ --> H[エラーを表示]
    H --> B

    G -- はい --> I[支払いを保存]
    I --> J[支払い状態を未配分にする]
    J --> K[支払い登録アクティビティを作成]
    K --> L[タイムラインへ表示]
```

---

## 負担額設定フロー

負担は割合ではなく、各メンバーの金額で指定する。

```mermaid
flowchart TD
    A[未配分の支払いを選択] --> B[負担額設定画面を開く]
    B --> C{入力方法を選択}

    C -- 金額を個別入力 --> D[各メンバーの負担額を入力]
    C -- 均等に分ける --> E[支払額を均等配分]
    C -- 一人が全額負担 --> F[対象メンバーに全額設定]

    D --> G[負担額の合計を計算]
    E --> G
    F --> G

    G --> H{合計が支払額と一致するか}

    H -- いいえ --> I[不足額または超過額を表示]
    I --> C

    H -- はい --> J[負担額を保存]
    J --> K[支払い状態を配分済みにする]
    K --> L[負担設定アクティビティを作成]
    L --> M[請求作成へ進む]
```

---

## 請求作成フロー

請求は「ユーザーから指定財布への返済依頼」として作成する。

```mermaid
flowchart TD
    A[配分済みの支払いを選択] --> B[負担額を取得]
    B --> C[支払元財布を取得]
    C --> D{支払元財布の種類}

    D -- 個人財布 --> E[財布所有者以外の負担額を抽出]
    E --> F{請求対象があるか}
    F -- ない --> G[請求を作成しない]
    F -- ある --> H[請求内容を生成]

    D -- 共有財布 --> J[各負担ユーザーへの請求内容を生成]

    H --> K[請求先ユーザーを設定]
    J --> K
    K --> L[返済先財布を設定]
    L --> M[請求金額を設定]
    M --> N[対象支払いをClaimItemとして追加]
    N --> O[請求を保存]
    O --> P[支払い状態を請求済みにする]
    P --> Q[請求作成アクティビティを作成]
```

---

## 請求確認フロー

```mermaid
flowchart TD
    A[請求一覧を開く] --> B[自分宛の未精算請求を表示]
    B --> C[請求を選択]
    C --> D[請求詳細を表示]

    D --> E[請求金額を確認]
    D --> F[返済先財布を確認]
    D --> G[対象支払いの内訳を確認]

    E --> H[返済を行う]
    F --> H
    G --> H
```

---

## 精算フロー

返済元財布はシステムで管理しない。

```mermaid
flowchart TD
    A[請求詳細を開く] --> B[指定された返済先財布を確認]
    B --> C[任意の方法で返済]
    C --> D[精算完了操作を行う]
    D --> E{精算完了としてよいか}

    E -- いいえ --> F[未精算のまま保持]
    E -- はい --> G[請求状態を精算済みにする]
    G --> H[精算完了アクティビティを作成]
    H --> I{関連する請求がすべて精算済みか}

    I -- いいえ --> J[支払い状態は請求済みのまま]
    I -- はい --> K[支払い状態を精算済みにする]
```

## 支払いライフサイクル

```mermaid
stateDiagram-v2
    [*] --> 未配分: 支払い登録
    未配分 --> 配分済み: 負担額設定
    配分済み --> 請求済み: 請求作成
    請求済み --> 精算済み: 全請求の精算完了
    配分済み --> 配分済み: 請求を作成しない
```

## 請求ライフサイクル

```mermaid
stateDiagram-v2
    [*] --> 未精算: 請求作成
    未精算 --> 精算済み: 精算完了
```

## アクティビティタイムライン

```mermaid
flowchart TD
    A[ユーザーが操作] --> B{操作種別}

    B -- 支払い登録 --> C[支払い登録アクティビティ]
    B -- 負担設定 --> D[負担設定アクティビティ]
    B -- 請求作成 --> E[請求作成アクティビティ]
    B -- 精算完了 --> F[精算完了アクティビティ]

    C --> G[実行ユーザーを記録]
    D --> G
    E --> G
    F --> G

    G --> H[対象データを記録]
    H --> I[実行日時を記録]
    I --> J[グループのタイムラインへ表示]
```

## 財布参照フロー

グループに所属するユーザーは、共有財布と個人財布を参照できる。

```mermaid
flowchart TD
    A[ユーザーがグループへ参加] --> B[グループ共有財布を取得]
    A --> C[各メンバーの個人財布を取得]
    B --> D[財布一覧へ表示]
    C --> D
```

---

## メンバー削除・脱退フロー

過去の支払い・請求・アクティビティは削除しない。

```mermaid
flowchart TD
    A[メンバー削除または脱退] --> B{未精算の請求があるか}

    B -- ある --> C[削除または脱退を制限]
    C --> D[未精算請求の解消を案内]

    B -- ない --> E[メンバー状態を脱退済みに変更]
    E --> F[個人財布を新規操作対象から除外]
    F --> G[過去の支払い・請求・履歴は保持]
```
